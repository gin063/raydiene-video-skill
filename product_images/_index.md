## 五、缺口（还没有的角度）

按目前用得上的机位排序，缺的是：

| 缺什么 | 影响 |
|---|---|
| **仰角与俯角**（全部 26 张俯仰角都是 0° 平视） | 需要仰拍/俯拍时只能靠正面+侧面外推，模型会瞎猜。**这是最大的缺口** |
| **背面** | 涉及安装底座、走线口的镜头没有依据 |
| **局部特写**（面板、枪座、格兰头、logo） | 特写镜头只能从全身图裁，分辨率与细节不足 |
| **右侧 90°**（现有侧视全是左侧） | 需要右侧视角时只能镜像，但镜像会让 logo 反字 |
| **收纳态**（线缆盘绕在挂钩上） | 成品展示镜头的关键状态，目前一张都没有 |
| **星耀/星辰的侧视与背面** | 大屏系列只有正面（0°）与斜角（+25°/+30°），没有 90° 侧视 |
| **星辰的「斜角 + 枪已插」** | 星耀四张齐全，星辰缺这一格 |

补图时按现有命名续号即可（如 `磐石pro8.png`），并在本文件对应表格追加一行。

2026-08-28 操作者已完成：背景统一、RGB 转换、压缩、星耀目录替换。

**背景为什么是白不是灰**：实测过 17 个候选底色，纯白的轮廓分离度最好（平均边缘对比度 110.7，
最差糊边 11.0%），中灰区间反而最差（对比度 60–69，糊边 16–20%）——因为这几款产品的轮廓边缘
整体偏暗（边缘亮度中位数 坚石 156 / 磐石 99 / 星耀 89），中灰正好压在分布中间。
纯黑分离度也高但会让模型把画面读成暗环境。详见 `../CHANGELOG.md`。
