# 物理自洽 · 穿帮清单

一个穿帮镜头的杀伤力大于十个平庸镜头。写 prompt 时预防，交付前逐条过。

> 本清单是初版，按实际踩坑持续补充。发现新的穿帮点，追加到对应小节并在 `../../CHANGELOG.md` 记一笔。

---

## 1. 充电枪与线缆

- **线缆是软的。** AI 极爱把充电线画成漂浮的硬管或粗细均匀的完美弧线。真实的线缆有自重、有垂坠、有堆叠，落地段会瘫软，挂在枪座上会形成不规则的自然垂弧
- **张力要与状态一致。** 枪插在车上时线是绷着还是松着，取决于车与桩的距离；枪挂在座上时线应当松弛
- **线缆长度与画面距离自洽。** 桩到车的距离若明显超过线长，就是硬伤
- **枪头插入方向与卡扣。** 枪与充电口必须同轴，卡扣位置朝向正确，不能斜插、不能反插
- **不得穿模。** 线缆穿透桩体、穿透地面、穿过车身——出图后重点看这个
- **手部姿势。** 握枪是虎口向下抓握柄，不是捏着枪头；拔插时另一只手常扶车身或按卡扣

## 2. 桩体、安装与场景

> 🔴 完整的安装场景构成见 `install-scene.md`。本节只列穿帮点。

- **必须有配电箱。** 一面墙上孤零零一台桩、没有任何配电设施，是最容易犯也最致命的穿帮
- **安装高度约 1.4–1.5 米**（面板中心）。画得太低像地插，太高不合人体工学
- **进线从桩体底部进，不是顶部。** 走向是：顶部下行 → 配电箱 → 横向短接 → 桩体底部
- **线管只走直角。** 弯成弧线的明管现实里不存在
- **线缆收纳态是盘绕成圈挂在桩体上、枪头插回正面下部的圆形插座**，不是挂在侧面挂钩上垂到地面
- **底座/膨胀螺栓**在特写里应当可见，不能悬浮贴墙
- **指示灯逻辑要前后一致。** 待机 / 充电中 / 满电 / 故障各是什么颜色、是否呼吸——同一支片子里必须统一，**首尾帧尤其不能互相矛盾**
- **屏幕内容自洽。** 显示的功率、电流、状态文字要与该时刻的剧情一致；未连接时不该显示充电功率
- **地下车库要有该有的东西**：层高、柱距、顶部管线、地面划线、层号标识、限高牌。空荡的灰盒子一眼是渲染图
- **露天车位**要有排水、墙面老化、光照随天气变化

## 3. 车辆

- **充电口位置随车型变**（左前翼子板 / 右前 / 右后 / 车头正中）。画面里车的品牌若不明确，就选一个位置并全片保持一致；同一辆车在不同镜头里换充电口位置是硬伤
- **充电口盖是打开状态**才能插枪，盖板的开启方向要合理
- **车灯行为**：解锁通常是双闪一次，不是持续闪烁；充电中部分车型有呼吸指示
- **车身反射**要与场景光源一致——车库顶灯该在车顶留下条状高光

## 4. 内部结构（3D 拆解轨道）

- **继电器触点是金属，不是塑料。** 银氧化锡触点呈银灰色，有金属光泽但不是镜面；工作过的触点会有轻微烧蚀痕迹（表现新品时可以是洁净的，但要有意识地选）
- **拆解要沿真实结构面分离。** 外壳沿接缝分开，不是把实心体切成两半；螺丝位置要与壳体上的螺柱对得上
- **爆炸视图的零件要能装回去。** 各零件的分离方向应当沿装配轴线，且间距均匀
- **PCB 要像 PCB**：元件排布有分区（功率区/控制区）、丝印方向基本一致、焊盘与引脚对齐、走线不穿元件
- **芯片引脚数不要随机。** 特写里能数清引脚时，数量应当合理且对称
- **丝印文字不要乱码。** 要么按 `image-prompt.md` 第 ⑫ 条明确指定内容，要么让特写避开丝印区域
- **尺度感**：微距下的元件表面应当有真实的加工纹理，不是光滑塑料感

## 5. 水、灰、粒子

- **水在不同表面行为不同**：疏水涂层上成珠滚落，普通塑料/金属上成膜下淌。同一镜头里表面材质不变，水的行为就不该变
- **水从上往下走**，会在边缘、缝隙、凸起处聚集后滴落，不是均匀铺满
- **演示防护等级时，水不进缝隙。** 这是这类镜头的全部意义——若画面里水渗进接缝，等于自证防护失效
- **扬尘是团絮状、有方向的**，不是均匀的雾。有风向就该有一致的飘散方向
- **灰尘落在水平面上**，垂直面积不住灰
- **粒子要有景深。** 近处的雨丝/灰粒应当比远处的大且更虚

## 6. 光与影

- **影子方向与主光一致**，且全片同一场景的光位不能跳
- **发光物要照亮周围。** 指示灯亮起时，灯罩周边、临近墙面应有微弱光晕；只有灯本身亮而环境毫无反应，一眼是贴图
- **首尾帧的光必须一致**，除非光本身就是变化量（如灯亮起）
- **混合色温**是真实感来源：车库冷白顶灯 + 车尾灯暖红 + 屏幕蓝光

## 7. 人物

- **手指数量、关节朝向**——特写有手时必查
- **人与桩/车的尺度关系**要与安装高度自洽
- **无感启充类镜头**：手机在口袋里不应该发光；人的视线朝向应当与剧情一致（不看手机才是「无感」的卖点）
- **步幅与距离**：首尾帧之间人移动的距离，要与镜头时长下的正常步速对得上

## 8. 首尾帧之间的连续性（视频链路特有）

这一节是本清单里最容易被忽略、但最致命的一组。

- **不得凭空出现或消失。** 尾帧里有的物体，首帧里要么已经在、要么有合理来源（从画外进入）
- **不该变的一律不变**：机位、焦段、光位、色温、地面材质、周边陈设、产品外观
- **时间跨度合理**：尾帧是「镜头时长之后」的样子，不是很久以后
- **状态变化单向**：不要首帧灯是黄的、尾帧是绿的，而剧情是「报警」

## 交付前逐条过

```
□ **断头检查**：每根线、每根管两端都有着落，无凭空消失
□ 进出线不接反：进线在底部左（白管包覆），出线在底部右（黑缆）
□ 有收纳挂钩，线缆盘在上面，枪头已归位
□ 线缆：软、有垂坠、张力与状态一致、不穿模
□ 枪头：同轴、卡扣朝向对、手部握姿正确
□ 桩体：高度 1.2–1.5m、走线有来源、底座着墙
□ 指示灯与屏幕：颜色逻辑全片一致，首尾帧不矛盾
□ 场景：有该有的标识与陈设，不是空盒子
□ 车辆：充电口位置全片一致、口盖已开、灯行为合理
□ 内部结构：沿接缝分离、零件能装回、PCB 合理、无乱码丝印
□ 水/灰：行为符合材质、防护演示中水不入缝、粒子有景深
□ 光影：影向与主光一致、发光物照亮周围、首尾帧光一致
□ 人物：手指、尺度、视线、步幅
□ 连续性：无凭空增减、不该变的没变、时间跨度合理
```
