## 2. Kling 的两条关键语法

### Custom Multi-Shot —— 一次生成多镜头连续段

开 Multi-Shot 模型自动规划转场；开 Custom Multi-Shot 可逐镜指定内容与时长。
**官方示例带秒数**，照抄这个形状：

> `Shot 1 (2s): Wide shot, @Boxer A and @Boxer B face off in the center of the rooftop...`
> `Shot 2 (2s): Both move in, testing each other up close...`
> `Shot 3 (3s): @Boxer A continues the attack...`

中文同构：`镜1（2秒）：桩体正面中景，三条监测线路从桩体向外延伸展开。镜2（2秒）：……`

**这是处理连续段的首选路径**，转场由模型内部完成，无拼接痕迹。见 `frame-strategy.md` 第 9 节。

### @ 引用绑定的元素

上传并绑定为 element 后，在正文里用 `@名称` 直接引用，比再描述一遍外观稳得多：

> `@Kling Lipstick` `@Image` `@Boxer A` `Mid-shot, background @Image.`

产品参考图**多于一张时优先走这条**（2–4 张多角度绑定），比只在首帧里画出来强。
Omni 还支持多元素混合，且各元素独立锁特征。

### 时间锚点（长镜头节奏）

官方 15 秒示例用逐秒点名控制节奏，不是靠形容词：

> `At the 4th second, ... At the 8th second, ... In the final 3 seconds, ...`

### 3.0 还是 Omni

Omni 在**多元素融合与一致性**上更强（多主体同框各自锁特征、视频元素、音色绑定）。
我们的片子只有一个产品主体、没有角色对白，**3.0 够用**；除非同一镜里要同时锁产品 + 场景 + 车三个参考。

## 3. Seedance 2.5 的三模块 prompt 结构

官方手册给的正文组织方式，与本 skill 的十三要素不冲突——**十三要素管「写什么」，三模块管「怎么排」**。
走 Seedance 时按这个顺序摆。

### 模块一 · 多模态参考层
> 公式：`基于上传的[参考素材类型]，严格保持[…]一致，严格锁定[…]。`
> 官方例：`基于上传的[图片]，严格保持@图1的人物[面孔/特征]一致性，保持@图2的[构图/白模/空间关系]一致，严格锁定人物站位。`

**全文可以多次 @图/@视频/@音频，官方说会更准。** 没上传参考素材就跳过本模块。

### 模块二 · 全局设定
> 公式：`[基础环境与质感]+[视觉风格]+[镜头语言]+[主体造型]+[表演核心]+[禁止项]`

其中**主体造型**（非人物）的公式对我们特别合用：
> `[数量词] + [颜色] + [外形/设计风格] + [具体物品名词] + [材质细节/磨损状态] + [标志性特征]`

**禁止项**官方建议从四个方向下手：`[声音]+[字幕]+[行为]+[容易崩坏的地方]`。
我们的标配：`禁止生成字幕，禁止生成多余台词或 BGM，禁止产品形变或 logo 改变，禁止线缆穿模。`

### 模块三 · 时间戳剧本分镜
> 每段切片：`[开始秒数-结束秒数] + [核心阶段/主题]` → `[动作等物理层面指令]` → `[镜头调度/深层意图]`

Seedance 侧的多镜头与节奏控制走这个，等价于 Kling 的 `Shot N (Ns):`。

### 转场公式

官方手册在**视频延长**章节给出，用于延长段与前段之间的切镜：

> `切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]`
>
> 1. 需要在切镜处使用「X」转场（**禁止生硬切镜、禁止物体凭空出现**）
> 2. 保持镜头呼吸感与时长协调，留出足够切换时间，让画面 A 自然过渡到画面 B
> 3. 要求必须自然切换场景（可再加景别变化，如「景别由特写转为中景」）

官方列出的转场类型：**自然镜头切换 / 淡入淡出 / 叠化 / 白闪·黑闪 / 擦除 / 遮罩转场**（另有水墨、相似物等）。
也可以列几个让模型自选：`请从[自然镜头切换/遮罩转场/相似物转场]中，根据本片风格选择最合适的一种。`

> 🔴 **纠正第二条早期误判**：我曾按社区 skill 的禁用清单写「不要让模型做黑场/渐显/叠化」。
> **官方手册专门提供了这些转场的 prompt 公式**，能力是有的。
> 底层判断只有一半成立，改成条件式，见 `video-prompt.md` 第 8 节：
> **连续段内部的镜间转场用官方公式；交付给剪辑的独立片段首尾不要自带转场。**

### 2.5 另外几个可能用得上的

| 能力 | 对我们的用处 |
|---|---|
| **多宫格分镜** | 输入多宫格分镜图当剧情参考，官方推荐**简约线稿/火柴人**。适合先手绘连续段节奏再交给模型 |
| **白模控制**（官方英文 Clay Renderer） | 镜头调度、站位、运动轨迹的工业级控制；有 Maya/Blender 插件导 Camera 路线。支持粗/细颗粒度，官方说**粗颗粒度效果更好** |
| **智能编辑 / 圈选标记编辑** | 手册第 3 节另有专门的 prompt 写法，本 skill 暂未用上 |
| **绿幕编辑** | 要在后期叠加监测图标、数据 UI 时，让底层出绿幕 |
| **局部消除与编辑** | 只改画面里某个元素，不重新生成整段 |
| **视频延长 / 超长视频** | 单次 30s 内可套娃延长至 60s；超长模式一次 30–180s |

## 4. 分流规则

用户口述的定性判断：**Kling 适合静物摄影；Seedance 适合长片，总体更强大但更贵。**
两边现在都支持首尾帧和多镜头，所以分流看的是**强项和成本**，不是有无。

| 镜头特征 | 走哪个 | 为什么 |
|---|---|---|
| **产品静物、结构特写、质感** | **Kling 3.0** | 静物是其强项（用户实践判断） |
| **画面内文字必须准** | **Kling 3.0** | 原生文字保持能力，官方点名电商广告 |
| **10 秒内的连续段** | **Kling 3.0 Custom Multi-Shot** | `Shot N (Ns):` 逐镜控时长，一次出完 |
| **超过 15 秒的连续演进** | **Seedance 2.5** | Kling 上限 15s；Seedance 单次 30s，超长模式到 180s |
| **要绿幕/白模/局部改** | **Seedance 2.5** | Kling 无对应能力 |
| **同镜要锁 3 个以上参考主体** | **Kling 3.0 Omni** | 多元素独立锁特征是 Omni 的强项 |
| 成本敏感的试错轮 | Seedance 2.0 Fast | 约 0.2 元/秒，是 2.5 的一半 |

**默认走 Kling 3.0。** 我们的片子以产品静物、结构特写、状态变化为主，单镜都在 15 秒内，
且画面内有必须准确的参数数字——三项全在 Kling 强项上。

⚠️ **混用两个模型会有质感差异**（噪点、色彩、运动模糊各不相同）。要混用就在确认单里说明，
让剪辑侧有准备；能不混就不混。
