# 充电桩安装场景 · 构成与逻辑

> 依据：2026-08-28 操作者提供的三张真实安装实拍图（地库毛坯墙 / 黄白涂装墙 / 蓝白涂装柱面）。
> **这一份是纠错纪录。** 第一版镜头表凭想象写的安装场景在四个地方是错的，全部列在第 5 节。
> 写任何含真实安装环境的镜头之前，先读这一份。

---

## 1. 桩体底部有两根线，走向相反，不能混

这是整份文档最重要的一张图。**桩不是单独挂在墙上的**，它是一条链路的末端；
而且**它底部同时有进线和出线，方向相反**。

```
          顶部电源（桥架 / 母线槽 / 公共配电间）
                    │  竖直线管沿墙下行
                    ▼
       ┌──────────────────┐
       │  配电箱（漏电保护）│  ← 装在桩体【左侧】
       │  黄色「当心触电」标 │
       └────────┬─────────┘
                │ 白色 PVC 横管，沿墙【向右】
                └──┐
                   │ 90° 弯头折上
                   ▼
         ┌───────────────────┐
         │   充电桩            │
         │  ┌─────────────┐  │
         │  │ 条形指示灯    │  │
         │  │ 刷卡区        │  │
         │  │ ◉ 圆形枪座 ←──┼──┼─── 枪头插在这里
         │  └─────────────┘  │
         └──┬─────────────┬──┘
       进线口↑            ↑出线口
       （左，接白管）    （右，出黑缆）
                          │
                          │ 黑色充电线缆向下
                          ▼
                    ╔═══════════╗
                    ║ 墙面金属挂钩 ║ ← 桩体正下方约 40cm
                    ║ 线缆盘 5–6 圈║
                    ╚═══════════╝
```

**两根线各自的完整交代**：

| | 进线 | 出线 |
|---|---|---|
| 位置 | 桩体底部**左侧** | 桩体底部**右侧** |
| 是什么 | 电源线，**被白色 PVC 管包覆** | **黑色充电线缆**，裸露 |
| 从哪来 | 配电箱底部，沿墙横向右行、90° 折上 | 桩体内部 |
| 到哪去 | 接入桩体底部进线口 | 向下 → 盘绕在墙面金属挂钩上 → 末端枪头插回正面圆形枪座 |

🔴 **配电箱放左侧。** 进线接底部左侧，箱子若放右侧，横管就得从桩下交叉穿过，
既不合施工习惯也难看。左侧是最短路径。

## 2. 🔴「断头」检查

**画面里每一根线、每一根管，两端都必须有明确去处。** 一端消失在画面外可以，
但那必须是「延伸出画外」的明确走向，不能是「画到一半没了」。

第一版的失误就在这里：黑色充电线缆只写了「盘绕成圈挂在桩体上」，
**没交代它从哪儿出来、盘完之后末端在哪**——等于两头都糊过去了。
读者一眼看不出问题，但画面会莫名其妙地不对劲，因为大脑在找那根线的尽头找不到。

同样要检查的还有：线管有没有上游、配电箱有没有进线、枪头有没有归位、
挂钩有没有固定在墙上。**每一个物件都要能回答「它连着什么、靠什么固定」。**

## 2.5 各环节的实拍特征

### 配电箱（**必须有，不能省**）
- 独立的方形防水箱体，约 200×150mm，灰白色或白色
- **正面贴一枚黄色三角形「当心触电」警示标**——画面里辨识度最高的元素之一
- 装在桩体**左侧**，高度与桩体相当或略高
- 商用/公共车库的箱体上常有手写或打印的编号标签（如 `C36a`、`C327`）
- 一个墙面上可能并排两个箱（一个计量、一个保护）

### 线管
- **两种材质，按环境选**：
  - **白色 PVC 管** —— 住宅地库、精装环境，配白色管卡与标准弯头
  - **镀锌金属管** —— 商用车库、有消防要求的场所，配金属管卡
- 走向：顶部下行接入配电箱顶 → 配电箱底部横向右行 → 90° 弯头折上 → 桩体底部左侧
- **转角一律用 90° 标准弯头，不走斜线、不走弧线**，管卡间距均匀

### 黑色充电线缆与收纳
- 线缆很长（常见 5m / 7m），**必须有收纳方案，不能让它散在地上或凭空消失**
- 标准做法：**桩体正下方约 40cm 的墙面装一只 U 形金属挂钩**，线缆盘绕 5–6 圈挂在钩上
- 枪头从线圈引出，**插回桩体正面下部的圆形枪座**（不是挂在侧面挂钩上）
- 盘绕要有自重感：圈与圈不完全重合，下缘略松垂，不是画得像标准同心圆

### 安装高度
面板中心距地面约 **1.4–1.5 米**。挂钩在其正下方约 40cm 处。

## 3. 墙面与环境的两种典型态

### 毛坯态（未完工）
- 清水混凝土墙，未粉刷
- 🔴 **规则分布的圆形穿墙螺栓孔（对拉螺杆孔）** —— 直径约 3–5cm，横竖成阵列。
  这是毛坯混凝土墙辨识度最高的特征，比「模板拼缝、麻面」有效得多
- 局部挂灰痕迹、墙根浮浆
- 顶部裸露楼板、桥架、消防管道，照明临时

### 完工态（已交付）
- 🔴 **不是整面刷成一个颜色。** 地库墙的标准做法是：
  **白色墙面 + 一条横向彩色色带（黄色或蓝色）+ 上下各一条白色分隔带**
- 色带高度大致与桩体安装位置重合，桩就装在色带上
- 地面：环氧地坪或原色水泥，常有**深绿色或深灰色踢脚带**
- 顶部：桥架包封或保留镀锌方管风管，消防管刷红，条形 LED 照明

第一版写的「整面刷成浅灰白涂料」是错的，太素、不像地库。

## 4. 产品形态（磐石Pro，2026-08 实拍）

- **竖长圆角胶囊形**，不是方正矩形
- 银灰色金属质感外框，包裹一块黑色玻璃面板
- 面板上部：一道**横向条形指示灯**（实拍见过绿色与蓝色两种状态）
- 面板中部：刷卡感应区图标
- 面板下部：**圆形充电枪插座**
- 桩体在墙上的投影明显，说明有一定厚度、离墙有间隙

⚠️ **这一节会随产品换代过期。** 通用规则是：
**prompt 里的形态描述必须与所挂参考图一致。** 描述和参考图打架时，模型两边都不听，
出来是个四不像——第一版写「极简方正」而参考图是胶囊形，就是这个错。
不确定产品长什么样，**先问，不要猜着写**。

## 5. 第一版错在哪（对照表）

| # | 第一版写的 | 实际 | 后果 |
|---|---|---|---|
| 1 | 「极简方正的壁挂式充电桩」 | 竖长圆角胶囊形 | 文字与参考图打架，模型出四不像 |
| 2 | 没有配电箱 | **必有独立防水配电箱 + 黄色警示标** | 电从哪来没交代，一眼假 |
| 3 | 线管从桩体上方向上延伸 | 顶部下行 → 配电箱 → 横向 → **桩体底部**进线 | 走线逻辑反了 |
| 4 | 线缆挂枪座、垂弧近地 | 收纳态是**盘绕在桩体下方的墙面金属挂钩上，枪头插回正面圆形枪座** | 不像成品 |
| 4b | **黑缆两端都没交代** | 底部右侧出 → 下行 → 盘在挂钩上 → 末端枪头归位 | 「断头」，画面莫名不对劲 |
| 4c | 配电箱放在桩体右侧 | 放**左侧**，进线接桩体底部左侧 | 放右侧要交叉走线 |
| 5 | 完工墙面整面浅灰白 | 白墙 + 横向彩色色带 + 白色分隔带 | 太素，不像地库 |
| 6 | 毛坯墙写「模板拼缝、麻面」 | 更标志性的是**规则阵列的圆形穿墙螺栓孔** | 特征不够准 |
| 7 | 安装高度 1.3m | 1.4–1.5m | 偏低 |

## 6. 写含安装场景的镜头时，逐条过

```
□ 有配电箱吗？在桩体【左侧】吗？箱上有黄色「当心触电」三角标吗？
□ **每根线两端都有着落吗？**（黑缆：底部右侧出→挂钩→枪头归位；进线：配电箱→横管→底部左侧）
□ 有收纳挂钩吗？线缆盘在上面吗？
□ 线管从哪来、到哪去？是不是「顶部下行 → 配电箱 → 横向右行 → 桩体底部左侧」？
□ 线管材质选对了吗（住宅精装白 PVC / 商用镀锌金属）？
□ 线缆是收纳态还是垂放态？说清楚了吗？枪头插在正面圆形枪座吗？
□ 安装高度 1.4–1.5m？
□ 墙面是毛坯态还是完工态？完工态有横向色带吗？
□ 毛坯态写了圆形穿墙螺栓孔吗？
□ 产品形态描述与要挂的参考图一致吗？
```
